# Baseline SAMoparser

Дата последнего запуска: 2026-11-15.

Команда:

```bash
make baseline
```

Скрипт читает текущую локальную PostgreSQL-базу и печатает фактические числа.
Он не меняет данные.

## Зафиксированные ограничения данных

- Excel не содержит подтверждённых закупочных количеств, цен, сроков действия,
  метрик лицензирования или назначений.
- Названия соглашений из Excel не являются юридической проверкой условий.
- Текущие `license_type`/`license_count` — legacy-поля прототипа и не должны
  трактоваться как реестр закупок.

## Последний фактический вывод

Вывод зависит от состояния локального volume PostgreSQL. Актуальное значение
перегенерируется командой `make baseline`; результаты не следует переносить в
production или считать юридическим заключением.
